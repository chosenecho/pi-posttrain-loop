# 短答档出题标准（short profile）

## 1. 目标与题量

从原始材料中提炼**天然适合 50–200 字一段直给**的极简快问，训练作者在日常快问、一刀切判断和术语大白话点破场景下干脆利落、一针见血的口语回应。

- **每篇出题数：0–1 题**（只挑全篇最适合一句话定性或单点点破的轻切口；不适合快问的纯长篇理论推导、纯叙事、带货通知或寒暄文稿直接返回 `[]`）。

## 2. 两类极简微切口（二选一）

1. **一刀切判断 / 态度快问（8–22 字）**：
   - 像普通读者随口抛出的真伪、靠谱与否或该不该做的问题（如“……这事靠谱吗？”“……和……是一回事吗？”“遇到……该不该直接……？”），不铺任何背景，也不追问长链条成因；
   - 让回答第一句直接拍板，再补一两句最硬的理由就能收住。
2. **单点概念 / 术语大白话点破（10–25 字）**：
   - 只拎出材料里的一个核心词、标签或常见说法，直问“用大白话讲到底指什么”或“跟平时说的……差在哪”，不问整个体系和历史演变。

## 3. 脱稿独立与精简红线

- **题干极短且单焦点**：严格控制在 **8–28 字**；禁止打包两个子问题，禁止“全面梳理”“系统分析”“展开讲讲”等必然逼出长文的问法。
- **脱离材料可独立理解 + 严禁幽灵前文（最高红线）**：
  - 起始题是对话第 1 轮，此前没有任何聊天记录；严禁以“你提到……”“你之前/前面说过……”“你又说……”“你自己也承认……”等默认刚聊过一段话的口吻开局；
  - 严禁出现“这段视频里”“上面提到”“材料中”“信里说……”“来信的同学”“刚才那个例子”等悬空指代；读信或答疑文稿必须抽离情境，转译为干净独立的公共短问。
- **准确归属立场**：不把作者批判或引述的他人观点错安到作者头上。

## 4. 避免的反模式

- 同一篇视频硬凑 2–3 题。
- 题干超过 35 字、自带背景铺垫的小作文式提问。
- 把作者原话的核心结论提前剧透进题干的泄题问法。
