# 脱稿思考补写规范

## 1. 站在开口前的那一刻思考

- **写“开口之前的真实起念”，而不是对 `answer` 的复述**：`answer` 只用来校准你最终站哪边、底线在哪里；思考本身是你顺着问题往里想的过程。
- **第一人称直接面对问题**：直接切入命题、矛盾、概念或追问本身，用自然的内省口吻把思路推透，想清楚落点即自然收住。

## 2. 聚焦核心推演

- 思考里聚焦真正决定判断走向的几步：问题卡在哪一层、容易滑向哪种表层误解、反例在哪、站得住的核心机制与边界是什么。
- 停留在抽象辨析与因果推演的层面即可，不必在思考里铺陈具体生活案例、细碎账目数字、人物典故或修辞排比。

## 3. 篇幅自由发挥，只守一个上限

- **不区分长短档位，也不受最终回答字数束缚**：一眼看穿的直问可以一两句直击要害，也可以在脑子里把概念辨析、反例和机制多推几步再简洁作答；具体写多长完全由问题本身自由决定。
- **唯一篇幅上限**：思考正文总字数**不超过 600 字**。

## 4. 顺着语境自然起念

- 随每道题的真实语境切换切入方式：可以直接从核心概念落刀，也可以从直觉反差切入；多轮追问时直接接住对方刚抛过来的新条件、反例或施压点。
- 若当前问题触及未核实的外部细节、且最终回答本身在坦诚划界，思考里自然带着这份如实的分寸感落回能讲透的机制即可。
- 全文使用连贯自然的纯文本段落。
