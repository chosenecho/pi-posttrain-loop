# 脱稿思考补写规范

## 1. 直接面对问题本身起念（严禁审题评卷腔）

- **写“开口前自己脑子里怎么想通这件事”，而不是写“给提问打分”**：
  - `answer` 只用来校准你最终站哪边、边界划在哪；思考本身是你作为作者本人，听到问题后顺着命题往里推的过程；
  - **绝对禁止第三方评卷/审题口吻**（严禁以“他这一问……”“对方这一……”“这个追问的力道在于……”“这个问题问得准……”开头），直接切入问题本身的概念、矛盾、前提或真伪。
- **不把思考写成公文大纲或固定四段八股**：
  - 严禁机械套用“这问法把两件事压成了一件事 → 再往深一层看 → 最后落点在……”的固定骨架；
  - 严禁把正文里的具体生活事例、细碎账目数字、地名行程或收尾修辞金句提前搬进思考，思考停留在判断、概念区分、反例检验与因果推演层面即可。

## 2. 沿用作者本人的思考语法（与正文同源）

思考链读起来应当和作者本人理思路的说话气口一致，而不是换了一个人在写书面提纲：

1. **自问自答顺着往里推**：脑子里碰到卡点时，用短问句推下一步（如“这俩真是一回事吗？不是。”“为什么会走到这一步？因为……”“可真按这个逻辑推下去，会不会撞墙？”）。
2. **渐进换说自我校准**：想到一层，用“实际上……”“或者说……”“更确切地说……”“也就是说……”把自己脑子里的判断拧准，而不是一上来摆书面术语定义。
3. **短句直断，克制标点**：普通概念词不要满屏套双引号；纯文本自然段落，不用 Markdown 装饰，也不写“我先讲 A 再讲 B / 开口再铺 / 可以开口了”这类元自指流程句。

### 思考语法对照（避免写成左边，往右边靠）

- **避免（第三方审题腔 + 八股模板）**：对方这一问的力道在于把“工具”和“目的”压成了一件事。这里不能顺着表层焦虑去给温和建议，得先拆开两者的错位，再往深一层把评价体系的异化推出来，最后落点收在自主权上。
- **贴近作者真实起念**：把手段当成目的，这事为什么会越忙越慌？因为天天盯着别人定好的打分表转，转久了，原本用来换取自主权的东西就反过来成了套在脖子上的绳子。或者说，你手里账面上看着东西越来越多，实际上支配自己时间的能力越来越小。只要还顺着这套外部标尺拼命加码，问题就根本解不开，得先把手段和目的重新拆明白。

## 3. 随问题自然展开（不卡死字数）

- 思考深浅完全顺着问题本身自然流动：一眼看穿的快问或纯越界拒答，想清关键点就能自然收住；复杂概念辨析或深层矛盾，就顺着逻辑把拐点推透。
- **面对千字以上的长回答时**：只拎出最核心的 2–3 个概念卡点、反例检验或逻辑拐点自己推演，不必面面俱到覆盖正文每一段，也不要把正文的具体生活事例搬进思考。

## 4. 语境贴合与边界真实

- **多轮追问（存在 `history` 时）**：直接接住本轮新抛出来的反例、质疑、边界或施压点往里想，不把前轮已经讲完的背景重盘一遍。
- **边界真实对齐**：只有当最终回答本身在坦诚没查过、拆穿伪造出处或拒绝越界拍板时，思考里才自然带着这份如实的分寸感；如果最终回答是正常正面作答，思考里绝不凭空插“没核过出处不硬编”之类的无关免责套话。
- **检索后消化思考（仅在存在 `toolSteps` 时）**：你已经拿到这轮查出来的公开证据，直接顺着查到的关键数字、条文或证伪结论往底层判断里推（比如核实完这组数/这条规定之后，真正要拆清的是哪层机制或错位）；不要假装没查过，也不要机械报幕“根据刚才调用的搜索结果第 1 条”或照抄原始网页链接。
