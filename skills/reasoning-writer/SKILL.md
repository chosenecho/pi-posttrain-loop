# 脱稿思考补写规范（自然第一人称内省）

## 1. 视角与定位

- **站在开口前的一瞬间往前想**：把目标回答当作你最终会抵达的立场落点，补写出“刚听完问题、准备开口前 2 秒”脑子里闪过的思路骨架。
- **直接面对问题本身，不写旁观点评**：用作者本人的第一人称内省语气，直接切入概念、矛盾或质疑本身；**严禁**用旁观者口吻点评提问者，**不要**以“他这里把……”“他这问法……”“他这一问……”“他追问的其实是……”“对方把……”“用户问的是……”“作者认为……”起手。
- **只抓主轴，懂得留白**：思考块是开口前的 2–3 个核心转折锚点，**绝不是把回答每一段压成提纲**。脑子里想透“误区在哪、关键区分在哪、边界卡到哪”就够了，具体案例、典故、细节论证以及正文收尾的锐利金句留给开口后的正文自然展开，不要在思考里提前剧透。

## 2. 思考内容只包含两到三个自然锚点

视问题复杂度自然组合，不必每条凑齐：

1. **戳前提或接锋芒**：识别命题里的概念错位、隐含假设，或多轮追问抛来的新条件与反例。
2. **定核心区分与立场**：明确判断支点、最关键的一道分界线或切入方向（点到方向即可，不必把具体例子全演完）。
3. **卡住本轮边界与落点**：直接把核心边界和不可退让的底线想清楚，自然收束即可；不要写成“推进顺序是先……再……最后……”“先把……说清，再落到……”这类发言步骤预告；多轮追问时直接顺着上轮话头接住新质疑，不重盘前轮已讲完的铺垫。

## 3. 强多样化起手（每次按题意自然变换）

刻意避开固定起手套路，按当前问题形态自然选用不同切入方式，例如：
- 直接从被问到的核心概念或命题落刀（先界定这个概念本身成立与否）；
- 先直面质疑里站得住的那一层，再划出转折边界；
- 先给一个简短直觉判断（“这两件事不能并列看”“这个前提本身就滑掉了”），再顺势把核心区分想清；
- 直接从最尖锐的反例或现实张力切入；
- 多轮追问时直接接住对方新抛的条件，把焦点钉在变化的那一步上。

## 4. 严格禁止的四类问题

1. **严禁后见抄写、结构预告与金句/案例剧透**：
   - 禁止照抄回答原句、修辞，也禁止在思考末尾提前剧透正文收尾金句或标志性警句；
   - 禁止按正文段落顺序每段压缩成一句，禁止把正文里的具体案例/人物典故全部提前塞进思考里；
   - 禁止写“推进顺序是先……再……最后……”“先把……说清，再把边界落到……”“我先说明……接着……最后收在……”这类显性行文步骤预告。
2. **严禁八股模板与列表排版**：
   - 禁止编号列表（`1. / 2. / 3.`、`第一、第二、第三`）、项目符号列表（`- / *`）、Markdown 符号（`#`、`**加粗**`）和“首先……其次……最后……”；
   - 禁止固定三段套话结构。
3. **严禁虚假内耗与硬凑字数**：
   - 思路清楚就干脆定调，不要刻意演戏写“等等，我是不是漏了另一个角度？再仔细想想……”。
4. **严禁生产元数据、规则泄漏与元自指收尾**：
   - 绝对不能出现“材料”“原稿”“文稿”“视频”“转写”“字数”“不超过”“目标档位”“禁止”“加粗”“Markdown”“参考答案”“金标”“要求”等词；
   - 禁止在思考末尾写“那是开口后再讲的事情”“剩下的交给开口再展开”“留到正文再说”等自指思考与正文分工的元口吻——想透核心转折与边界后直接自然停住即可；
   - 不要输出 `<think>`、`</think>` 标签。

## 5. 按档位控制思考篇幅

根据输入给出的 `targetThinkTier` 与 `targetChars` 精准控制篇幅，始终明显短于正文：

- **`short`（约 80–160 字）**：直击核心区分、前提错位或追问软肋，把关键判断与回应边界想清楚即止。
- **`medium`（约 120–230 字）**：抓住主要矛盾与关键分界线，把两三层关键转折自然想透，具体细节与金句留给正文。
- **`long`（约 180–340 字）**：针对复杂议题或尖锐追问，梳清核心层次与正反边界转折点；只留思考骨架与主轴锚点，绝不把正文各段细节、案例或收尾金句预先压缩进思考。
