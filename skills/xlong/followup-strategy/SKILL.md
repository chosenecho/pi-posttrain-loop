# 超长深挖档追问与收束策略（xlong profile）

## 1. 核心定位：多轮纵深拆解（2–3 轮为主）

在超长深挖档里，一道重磅母题通常需要 **2–3 轮** 才能把“总纲机制 → 反例与结构张力 → 边界与实践出路”真正打穿。

- **第 1 轮结束后**：只要 `material` 里还留有尚未展开的另一层结构机制、历史/现实反例或深层矛盾，积极提出有纵深的第 2 轮追问；仅当该题在 `material` 里的全部论点已彻底耗尽时才 `stop`。
- **第 2 轮结束后**：如果第 2 轮刚刚打开了更深一层的现实张力、实践困境或边界悖论，且 `material` 里仍有扎实依据可以继续推深一层，果断推进第 3 轮；如果两轮已经把材料里该主线的全部厚度吃干榨净，自然 `stop`，不要硬抬杠或重复前文。

## 2. 四类深水追问姿态（层层递进，不重复套路）

每次追问 **25–65 字**，像一个认真听懂了前两千字、顺着往深水区刨根问底的对话者：

1. **结构反例与极端处境检验**：抛出一个现实或历史中看似直接推翻上一轮判断的硬反例，问这套分析框架放进这个处境里怎么自圆其说、边界划在哪。
2. **顺推内在悖论与深层代价**：顺着上一轮的推论继续往深处走一步——指出按这个逻辑推下去在现实中可能撞上的两难或反噬，追问这层张力怎么解。
3. **跨层概念对照与历史迁移**：把上一轮讲清的机制放进另一个相邻领域或历史阶段里对照发问，检验这套框架的普遍解释力与限度。
4. **直击实践出路与行动困境**：在机制已经拆透的基础上，进一步追问具体处境中的人或群体面对这种结构性困境时，常见出路为什么走不通、真正站得住的方向应该抓什么。

## 3. 严禁串台与去套话红线

- **严禁串台**：凡是说“你提到……”“你说……”“你刚才讲……”的术语、案例或论断，必须严格出自 `history` 里前文助手实际说过的原话；若要借 `material` 里前文未出现的新概念或案例发问，只能以提问者自己举例子或换角度提问的方式自然引出。
- **去固定辩论套话与旁观词**：避免千篇一律用“照你这么说……”“这不就是……”“别绕弯子……”“你一边……一边……”起手；严禁出现“原文”“材料”“文稿”“作者”“视频里”“信里”以及“能再展开讲讲吗”“总结一下”等空洞水追问。
