# 反问澄清档出题标准（clarify profile · 双面出题法）

## 1. 目标与题量

现实中真实用户向作者提问时，经常因为当局者迷而**漏掉决定判断走向的 1–3 个核心边界条件**（例如只问“我现在该脱产考研还是先随便找个班上？”，却没交代家庭能不能兜底、本科学历和专业是什么、目前手头有没有保底offer）。如果回答者不追问清楚就瞎猜或写一套“情况A/情况B”的骑墙片汤话，既没有准度也丢掉了作者一针见血的定力。

本档专门采用**“双面出题法”**：
- **每篇出题数：0–2 题**（当文稿中包含明确的**分类轴、条件分水岭、不同处境截然相反的策略判断**时出 1–2 题；纯单行道公理阐述、无条件分支的纯概念介绍或通知促销文稿直接返回 `[]`）。
- **必须保存结构化任务契约**：调用 `save_questions(video_id, questions)` 时，`questions` 数组中的每一项**必须传入包含 `question`、`missing_slots` 和 `hidden_user_persona` 的对象**：
  ```json
  {
    "question": "表面自然简短、但故意隐去了关键分水岭条件的模糊提问（18–55字）",
    "missing_slots": ["被剥离的关键维度1", "被剥离的关键维度2"],
    "hidden_user_persona": "提问者被隐藏的真实具体处境（40–100字，明确交代其在各缺失维度上的真实底牌，供后台用户模拟器在回答者调用 question / questionnaire 时自动选出对应选项）"
  }
  ```

## 2. 两类核心“缺信息模糊题”构造方式（按缺失维度数量区分）

1. **单焦点分水岭缺失（驱动单问工具 `question`）**：
   - 文稿对某类问题划出了一条致命分水岭（例如：“有现金流兜底的稳态岗位”与“随时可能断粮的高波动外包/创业”策略完全相反；或者“真喜欢钻研本身”与“只是逃避就业压力”的做法完全相反）；
   - **出题做法**：在 `question` 中故意隐去这 1 个分水岭条件，模仿普通人上来就问“我现在该选 A 还是选 B / 这事该怎么破？”；同时把提问者真实的底牌写进 `hidden_user_persona`（`missing_slots` 含 1 项）。
2. **多维正交条件同时缺失（驱动多维问卷工具 `questionnaire`）**：
   - 文稿在分析某类复杂处境（如职业转型、婚恋矛盾、大额资源投入、学业规划、组织协作困境）时，同时取决于 **2–3 个互相独立的维度**（如：① 岗位/行业所处周期、② 手头容错安全垫厚度、③ 核心诉求是求稳还是博上限）；
   - **出题做法**：在 `question` 中只抛出一个看起来很急迫的笼统困惑（隐去这 2–3 个维度），在 `missing_slots` 列出这 2–3 个维度名称，并在 `hidden_user_persona` 中把提问者在这 2–3 个维度上的真实情况一一写死。

## 3. 脱稿独立与题干红线

- **表面 `question` 必须像真人的自然半截话，绝不自曝“我少说了条件”（最高红线）**：
  - 表面 `question` 长度 **18–55 字**，要像普通人没想周全时脱口而出的真实提问；
  - **绝对禁止**在 `question` 里写“我先不告诉你我的行业，你猜猜看”或“请用 question 工具向我提问”这种破次元提示！
- **`hidden_user_persona` 必须与文稿的核心分类轴严丝合缝**：
  - 隐藏画像里的真实处境必须能直接命中 `material` 中作者讨论过的某一条典型分支，确保当回答者按文稿框架列出 `options` 追问时，用户模拟器能清晰选出唯一契合的选项，且回答者拿到该选项后能依据 `material` 给出极其犀利、毫无废话的定论。
- **严禁幽灵前文与悬空指代**：
  - `question` 严禁以“你提到……”“你之前说过……”开局，严禁出现“这段视频里”“信里说……”“来信的同学”等悬空指代。
