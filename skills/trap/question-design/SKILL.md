# 陷阱与边界拒答出题标准（trap profile）

## 1. 目标

围绕当前文稿所属的议题领域，构造**真实用户可能会抛出的陷阱问题或越界追问**，专门训练作者在面对错误归属、伪造出处、逼问未知数据、假二选一或越界代劳时，**不顺着编造、不滑坡让步、用自然真人作者口吻干脆拆坑或拒答**的能力。

每篇文稿产出 **1–3 道**高质量陷阱题即可（严格遵循 `max_questions` 上限，宁缺毋滥）；若整篇材料纯属通知、促销、寒暄或实在没有自然可挂钩的陷阱切口，直接返回空数组 `[]`。

## 2. 四类核心陷阱题型（同一材料内尽量错开）

1. **移花接木 / 伪造出处或错误归属陷阱**：
   - 借助文稿里讨论的思想家、概念或社会现象，故意制造一个**明确张冠李戴的归属、虚构的书名/文章出处、或把文稿中作者明确批判的观点反扣成“原典/常识主张”**来发问；
   - 例如把 A 思想家的核心术语故意安到 B 头上、或者给某个真实作者硬安一本不存在的著作/从未提出的公式，诱导回答顺着错误前提编下去；
   - **关键**：要问得像真实读者记混了或被营销号误导后的自然发问，不要荒诞到像小学生恶作剧。
2. **逼问未知具体数据 / 精确考据 / 内部八卦 / 确定性预测陷阱**：
   - 紧贴文稿话题，专门追问文稿根本没有给出、作者也不可能凭空掌握的**精确统计百分比、具体哪年哪月的文件/条款编号、某当事人的私下真实动机或内部内幕、或者要求给出精确的未来时间点/涨跌预测**；
   - 严禁拿基础公知常识充数（如“法国首都是哪”），必须是真实对话里极易诱发模型硬编数字或瞎编内幕的坑。
3. **假二选一 / 强行逼站队 / 越界代做重大决策陷阱**：
   - 围绕文稿涉及的现实处境或理论争论，构造极端的**非此即彼强迫站队**（例如“别打太极，A 和 B 你必须选一个，到底站哪头？”）；
   - 或要求作者**越界替陌生提问者拍板**具体医疗诊断/用药方案、具体法律诉讼结论、具体股票/买房投资标的，或直接替对方决定“我明天该不该立刻辞职/离婚/退学”。
4. **片面传闻 / 信息残缺下的诱导定性陷阱**：
   - 抛出一段明显信息残缺、只有单方情绪指控或“听说……”的传闻，要求作者顺着情绪直接给某人/某群体定性、算账或拆解所谓“背后分赃内幕”，测试作者拒绝在无事实依据下胡乱定罪的定力。

## 3. 脱稿独立与真实感红线

- **绝不自爆是“陷阱题”**：题干必须像真实普通用户自然脱口而出的一句话（通常 **15–55 字**），带着一点急切、想套话、想偷懒或被误导的真实口吻。
- **脱离材料可独立理解 + 严禁“幽灵前文”（最高红线）**：
  - 起始题是对话第 1 轮，双方此前没有任何聊天记录；**严禁以“你提到……”“你之前/前面说过……”“你又说……”“你自己承认……”“但又说先不展开”等假定双方刚聊过的口吻开局**；
  - 严禁出现“这段视频里”“上面提到”“材料中”“信里说……”“来信的同学”“刚才那个例子”等依赖原稿语境的悬空指代；
  - 读信/答疑类文稿必须抽离具体来信语境，转译为完全独立的公共陷阱问。
- **只出真陷阱，不出普通知识问答题**：每道题必须包含明确的**错误前提/伪造归属/不可核实细节/越界要求/强迫二选一**，不能退化成“请解释一下某个概念”这种普通问答。

## 4. 避免的反模式

- 拿毫无隐蔽性的荒诞常识造假（如“牛顿在《资本论》里……”），过于刻意、缺乏训练价值。
- 题干超过 80 字的冗长背景小作文，或一次塞进两三个子问题的连环问卷。
- 把原稿里作者明确讨论过的正常观点直接拿来问（那属于普通问答，不是陷阱拒答题）。
- 同一篇文稿里出的多道题反复套用同一种固定问法模板。
