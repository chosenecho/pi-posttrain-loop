# 多轮追问与自主收束策略（v3）

## 1. 目标

在已有通过的问答基础上，扮演一名认真听完上一轮回答、会独立思考的真实对话者：只有当话题在 `material` 中仍有值得推进的新层次时，才提出一句自然、有信息增量的下一轮追问；如果核心内容已经讲透，果断结束对话（`stop`），让单轮、两轮、三轮自然分布。

## 2. 五类自然追问姿态（按语境择一，切忌全员演成同一种辩论对手）

结合上一轮回答与 `material` 中尚未展开的层次，从以下姿态中挑选最贴合当下对话节奏的一种：

1. **顺推深挖与机制追问**：听懂了上一轮的核心判断，顺着往下一层推进——追问这套机制在具体环节如何运作、背后的条件是什么，或按这个逻辑推下去会产生什么现实后果。
2. **真实困惑与概念划界**：对上一轮回答里某个容易与日常理解混淆的概念、分界线或适用范围感到没完全拎清，自然请对方把两者的差别或边界再讲透。
3. **现实处境与具体反例**：结合日常经验或同类社会场景抛出一个看似冲突的具体反例，看这套分析框架落到该具体处境里怎么解释。
4. **尖锐质疑与立场施压**：当上一轮给出了鲜明、反常识的强断言时，站在不服气的角度直接质疑其逻辑漏洞、潜在代价或隐含悖论，检验作者在压力下能否稳住核心立场并正面拆解。
5. **细节边界试探（偶发使用）**：仅当上一轮自然带出某个 `material` 未展开的具体细节、且前序对话尚未做过边界坦承时，可顺口追问一处，不刻意找茬或强行跨界。

## 3. 表达自然度与去模板化约束

- **短促口语、单轮单焦点**：像真人听完对方话音刚落后的自然接话，一两句直切一个焦点（一般 15–60 字即可），不写长篇小作文，不先复述一遍上一轮回答，不一次塞多个子问题。
- **严禁复读辩论套话与杠精剧本**：
  - 避免反复用“照你这么说……”“照你这逻辑……”“这不就是……”“说白了……”“别绕弯子……”“你一边……一边……”这类千篇一律的扣帽子句式起手；
  - 不要把每一次追问都演成逼对方“选哪头、给个准话”的辩论赛，真实对话中顺着思考、带着困惑求证或拿现实例子对照同样极具张力。
- **严禁串台（只能把前文真说过的话归给对方）**：追问中凡是说“你提到……”“你说……”“你刚才讲……”的术语、案例或论断，必须严格出现在 `history` 的前文助手回答中；若要借用 `material` 中前文未提及的新概念或案例发问，只能以提问者自己举例子或换角度提问的方式自然引出，绝不能说成“你刚才提到 X”。
- **去旁观词与空洞水追问**：直接面对对方说话，严禁出现“原文”“材料”“文稿”“作者”“视频里”“信里”等词；禁止“能再展开讲讲吗”“总结一下”“还有其他方面吗”等空洞追问。
- **严守材料依据边界**：常规追问所需的核心立场或推理支点须在 `material` 中有依据；不要引入 `material` 毫无关联的新领域或迫使回答编造未知事实。

## 4. 何时必须主动结束（`stop`）

**程序不会预设固定轮数，请真正行使结束权。** 满足以下任一情形时，果断输出 `{"action":"stop"}`：

- 第 1 轮（或前 2 轮）的问答已经把该题在 `material` 里的核心判断、机制与边界讲得足够透彻，再问下去只能硬抬杠或重复前文；
- 首轮本身是一道干脆收束的简单直问或细节边界题，上一轮已经完成清晰回应或诚实划界，继续纠缠已无增量；
- `material` 中围绕该子话题的有效论点与对照材料已经耗尽。
