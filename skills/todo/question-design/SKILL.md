# 长流程规划档出题标准（todo profile）

## 1. 目标与题量

从原始材料中提炼**天然包含 3–5 个递进逻辑阶段、不先列清单就极易漏项或逻辑塌陷**的复合型重磅问题，专门训练模型在回答复杂任务时调用 Pi `todo` 工具（`add` → 分步推演/检索 → `toggle`）进行内部结构化控场的能力。

- **每篇出题数：0–2 题**（优先在中长文稿、多 P 合集或包含多层结构推演的文稿中出 1–2 题；纯短平快寒暄、通知促销或单点小问题文稿直接返回 `[]`）。
- **推荐保存格式**：调用 `save_questions` 时，推荐传入带 `expected_phases` 的对象（也可传问题字符串）：
  `{"question": "...", "expected_phases": ["阶段1：...", "阶段2：...", "阶段3：..."]}`，其中 `expected_phases` 列出本题按原稿逻辑应当依次推进的 3–5 个实质子目标（仅供质检员核对，回答者不可见）。

## 2. 三类核心长流程题型（按文稿最契合的切口择一或组合）

1. **多维约束交织的处境诊断与分阶段破局**：
   - 提问者同时面临 2–3 个互相牵制的现实约束（如行业周期下行、家庭/债务刚性约束、个人技能或年龄卡点），要求回答者不能只给一句鸡汤，而是要把账面底牌拆清、把伪出路证伪、再排定先后止损与过渡的优先级。
2. **跨层次 / 跨分 P 的全链路机制推演**：
   - 抓住文稿中环环相扣的一整条论证链（如“表层观念误区 → 中层制度/利益分配机制 → 底层历史或结构成因 → 个体现实落点”），提出一个需要把这 3–4 层阶梯挨个踩实才能讲透的综合性大问题。
3. **多路方案/多组概念的正反对照与事实核验组合**：
   - 题干同时摆出两种或三种常见路线/思潮/现实策略（或涉及需要结合外部公开事实与原稿框架共同印证的复合议题），要求逐一拆开各自的隐性代价与适用条件，最后给出明确的取舍标尺。

## 3. 脱稿独立与题干红线

- **题干自然浑厚，绝不写成“考试大纲 / 机械指令单”（最高红线）**：
  - 题干长度以 **35–90 字**为宜，必须像一个带着复杂现实困境或深层理论困惑的真实提问者在自然发问；
  - **绝对禁止**在题干里帮模型列好清单（如“请分四步回答：第一步先讲A，第二步再讲B，第三步对比C，第四步给建议”或“请用 todo 工具拆解以下问题”）——怎么拆解步骤是回答模型自己调用 `todo` 工具的本事，绝不能在题干里剧透拆法！
- **题干信息必须完整自洽（与 `clarify` 档严格区分）**：
  - 本档训练的是**收到完整复杂任务后直接用 `todo` 拆解求解**，因此如果涉及具体处境，题干里必须把关键前提条件交代清楚，不要故意留致命缺口逼回答者去反问。
- **严禁幽灵前文与悬空指代**：
  - 起始题是对话第 1 轮，严禁以“你提到……”“你之前说过……”“你又说……”开局；
  - 严禁出现“这段视频里”“上面提到”“材料中”“信里说……”“来信的同学”等词；读信/答疑文稿必须把具体来信情境抽离转译为完整自洽的独立问题。
