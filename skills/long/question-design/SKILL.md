# 长答档出题标准（long profile）

## 1. 目标与题量

从原始材料中提炼**天然需要 550–950 字（2–4 个自然段）展开论证**的纵深问题，重点考察作者的概念划界、完整因果推导以及把框架落到具体现实里的解释力。

- **每篇出题数：1–3 题**（按内容纵深自然决定，多 P 文稿分散覆盖；过短浅层、纯通知、卖货或寒暄文稿返回 `[]`）。

## 2. 三类纵深切口（出 2 题时尽量错开）

1. **易混概念辨析与边界拆解**：
   - 把材料里的核心概念与表面相似、日常极易混为一谈的说法对照发问，追问两者的根本差异、适用范围以及把它们混掉之后会导致什么偏差。
2. **完整因果链条与矛盾机制深挖**：
   - 不只问表层“对不对”，而是顺着材料里的关键矛盾发问：某个现象或观念是怎么一步步演变成今天这种结果的？中间哪几环在互相拉扯、互相强化？
3. **现实迁移与代价取舍分析**：
   - 把材料里的分析方法放进同类现实处境、制度环境或人生两难里发问，要求讲清背后的利害结构、为什么常见解法会失效、以及真正可行的出路要付出什么代价。

## 3. 脱稿独立与题干红线

- **题干扎实但不过度喂饭（22–60 字为宜）**：直指核心矛盾或概念对照，一题一焦点；不要写成“你提到 A 又指出 B，那么怎么看 C？”的顺风访谈提纲，也不要提前把答案结论剧透进题干。
- **严禁幽灵前文与悬空指代（最高红线）**：
  - 起始题是对话第 1 轮，严禁以“你提到……”“你之前/前面说过……”“你又说……”“你自己也承认……”开局；
  - 严禁出现“这段视频里”“上面提到”“材料中”“信里说……”“来信的同学”“刚才那个例子”等词；读信/答疑文稿必须把具体情境抽离转译为完整自洽的公共问题。
- **准确区分立场归属**：除带着常见误解发问外，不把作者批判或引述的他人观点错安到作者头上。

## 4. 避免的反模式

- 一两句话就能答完的轻快是/否问（那属于短答档，会逼着回答硬灌水凑字数）。
- 泛泛而谈的总结题（如“总结一下主要观点”“怎么看这个话题”）。
- 把三四个互不相干的小问题打包成问卷。
