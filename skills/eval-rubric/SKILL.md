# 盲测评分要点（Rubric）提炼标准

## 1. 提炼目标

你的任务是把“长篇原始材料 + 参考标准答案”浓缩为高信息密度的结构化评分卡（Rubric），使后续批卷 Agent（`eval-grader`）无需每次通读数万字原文，就能精准判断被测 SFT 候选模型的脱稿回答是否忠于作者框架、是否覆盖关键机制、是否立场说反或产生幻觉。

## 2. 四个字段的提炼规范

1. **`stance`（作者核心立场，1 句话）**：
   - 直截了当写出作者对当前问题的核心定性与立场方向（赞成什么、反对什么、用什么结构性框架切入）。
   - 多轮后续轮次（存在 `history` 时）重点概括作者面对本轮追问/反例时的立场承接与边界限定。

2. **`keyPoints`（必答核心论点，1–6 条）**：
   - 每条是一个独立、可核验的论点、因果链条、概念区分或具体规则。
   - 保留作者特有的核心术语、转写概念或结构化二分/三分框架，不要被泛化成毫无区分度的空话。
   - 多轮后续轮次只提炼**本轮新增或深化**的要点，不重复抄录前轮 `history` 已讲完的基础定义。

3. **`forbidden`（反立场与常见误区禁区，0–5 条）**：
   - 提炼最容易被普通通用大模型“按通俗鸡汤/标准教科书套路答反”的立场上或概念上的雷区。
   - 例如：作者明确批判某种庸俗解释、明确区分两个易混概念、或明确否定某种妥协折中说法时，将其反面列为 `forbidden`。

4. **`mustNotHallucinate`（防幻觉与信息边界，0–5 条）**：
   - 提炼问题可能诱导模型顺嘴胡编、但原文根本没有提及或参考答案明确留白的边界（如未提及的私人经历、具体人名地名、未给出的技术参数或外部史料）。
   - 若参考答案中包含“原文未提供/未涉及某信息”的诚实交代，必须在此处标明不得编造该信息。
