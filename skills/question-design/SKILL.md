# 出题质量标准

## 1. 目标

从原始材料中挖掘能充分展现作者判断方式、理论框架、立场辨析与表达特点的高价值起始问题，使生成的问答既适合单轮训练，也为后续多轮深度追问留出自然空间。

## 2. 优先挖掘的 5 类问题

1. **核心概念界定与拆解**：作者对关键概念给出的独特定义、结构分析或拆解方式（例如“你所说的 X 究竟指什么？”）。
2. **因果与机制解释**：为什么会出现某种社会、心理、历史或制度现象，内在运作机制是什么。
3. **立场对比与概念辨析**：作者如何区分两种或多种看似相近、容易混淆或彼此对立的立场、流派与概念。
4. **价值判断与代价权衡**：作者在两难或多方立场之间为何倾向某种取舍，其背后的衡量标准是什么。
5. **有依据的现实观察与建议**：材料明确展开的现实判断、实践原则或对常见误解的纠偏。

## 3. 提问规范

- **脱离材料可独立理解**：把问题当成真实用户直接向作者发问；禁止出现“这段视频里”“文章上面提到”“材料中说的那件事”等依赖上下文的指代。
- **自然对话口吻**：像一个有思考的真实听众或读者在提问，避免考试大题腔或机械问卷腔。
- **一题一焦点**：每道题围绕一个明确核心意图展开，保留必要前提条件，不要把三四个松散子问题硬打包成一题，也不要把完整答案提前塞进问题里。
- **严格区分立场归属**：准确区分作者本人的观点、作者转述的他人或学派观点，以及作者正在批评的观点；绝不把作者反对或引述的观点错说成作者自己的主张。
- **严控题量上限、拒绝单篇过度榨取**：严格遵守输入中的 `max_questions` 上限（0 至 `max_questions` 题），同一核心论点只出一道最具代表性的题，绝不把同一段话翻来覆去换皮出题；若材料仅为寒暄、通知、过场或缺乏实质观点，果断返回空数组 `[]`，绝不凑数。
- **多 P 文稿均衡覆盖**：当输入 `part_count > 1`（或正文含多个 `## P00x` 分 P 章节）时，应通览全篇各分 P，按信息密度在各分 P 间均衡选题，避免只盯着 `P001` 出题。
- **长短与深度层次搭配**：题组内自然搭配“直奔单一判断的定性/概念短问题”与“需要多层因果拆解或权衡的深度问题”，避免所有题目都长成宏大论述题。

## 4. 禁止生成的反模式

- 泛泛总结题（如“请总结一下这篇内容的主要观点”“你怎么看这个话题”）。
- 脱离作者思想特征的纯百科送分题（如某人物生卒年份、地名拼写）。
- 诱导作者编造材料未提及的私人经历、未公开立场或无关领域的跨界问题。
- 仅换了措辞但核心意图完全相同的重复题。
