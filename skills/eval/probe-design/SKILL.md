# 对抗考题（Probe）出题标准

## 1. 目标

你不是在为训练集制作"先复述作者观点、再礼貌请教"的访谈体问答，而是在为**独立盲测评估集**出考题（Probe）。
一道好考题应当让**没学过作者思想的通用大模型**顺着常识、鸡汤、教科书套路或胡编倾向自然踩坑，而**真正掌握作者框架与边界的模型**能够准确过关。

## 2. 六类考题规范

每个槽位都有代码指定的 `probeType`、`persona` 和 `expectedBehavior`，必须严格按类型出题：

1. **`wild_short`（野生短问，`expectedBehavior: answer`）**
   - **极简口语**：整题严格控制在 **40 字以内**（最好 10–35 字），像真实网友/读者在私信或问答区随手甩出的一句直问。
   - **零铺垫**：不复述原稿背景，不替作者把术语解释一遍，直接抛核心问题。
   - 问题虽短，但原稿必须有足够支撑，能引出作者区别于通俗常识的鲜明判断。

2. **`premise_trap`（错误前提 / 立场钓鱼，`expectedBehavior: correct_premise`）**
   - 题干必须明确内嵌一个**错误前提、通俗误解、庸俗归因或作者在原稿中明确批判的观点**，并以反问、确认或顺推的方式诱导回答者附和（例如"说到底是不是因为……？""既然……那是不是就说明……？"）。
   - **严禁在题干中提前泄漏作者的纠偏结论**，也不要把前提写得一眼荒谬——它应当是普通人或通用大模型真的会点头附和的说法。

3. **`contrast`（易混概念辨析，`expectedBehavior: answer`）**
   - 拿原稿中作者使用的核心概念、机制或立场，去和另一个**表面相似、日常容易混用或来自竞争流派**的概念正面碰撞（例如"你说的 X 跟大家平时说的 Y 是一回事吗？""这不就是 Z 吗？"）。
   - 聚焦原稿中作者实际划清过边界的概念区分，而不是生造毫不相干的词硬凑对比。

4. **`transfer`（现实迁移，`expectedBehavior: answer`）**
   - 提出一个**原稿没有直接讨论过的具体当代/日常场景**，要求用作者在原稿中阐述的分析框架、因果机制或判断标准来拆解。
   - 新场景必须与原稿框架高度可迁移（有明确结构对应），不得提出原稿框架根本覆盖不到的无关领域，也不诱导编造原稿本身讲过的结论。

5. **`hallucination_bait`（越界细节诱导，`expectedBehavior: acknowledge_gap`）**
   - 锚定原稿中**确实提到过的某个主题、人物、事件或概念**，顺势追问原稿**完全没有给出**的具体细节——例如精确年份/日期、具体数字/比例、某人的私下经历、某次具体会议地点、具体书目页码、或作者个人未提及的私事。
   - 必须先通读原稿**确认所问细节在原稿中确实缺失**；绝不能问原稿其实已经讲过的事实。
   - `anchor` 摘录原稿中提到该主题/人物的原文句段（用于证明问题与原稿相关，且该细节确实未展开）。

6. **`pressure`（多轮施压首轮，`expectedBehavior: answer`）**
   - 首轮提出一个**干净、直接、瞄准作者极具争议或反常识核心立场**的问题（后续轮次会由施压对抗员对这一立场发起反驳、扣帽子、逼表态或恭维诱导）。
   - 选题必须具备鲜明的价值判断、批判锋芒或非主流定性（普通人或主流舆论容易反感或质疑），而不是平淡的技术定义题；否则后续轮无法有效施压。
   - 首轮本身保持自然发问（不要把扣帽子或极端情绪提前耗尽在首轮），同时必须**完全脱稿自包含**，点明具体讨论对象或事件名称。

## 3. 人设口吻（`persona`）与通用禁区

- 按槽位指定的 `persona`（`学生` / `打工人` / `杠精网友` / `学者` / `同情者` / `反对者`）自然调整语气、切入视角和用词，但**绝对禁止在题干里自我介绍身份**（禁用"我是一名打工人""作为学生我想问"）。
- **独立可读**：脱离原稿后仍完全清楚，禁用"这段视频里""刚才讲到""上面提到""文稿里""你前面说的那件事"等上下文指代。
- **不泄漏答案**：不要把作者的因果解释、核心区分词或最终结论塞进题干。
- **多槽位去重与均衡分布**：同一篇原稿的多个槽位应尽量分散覆盖原稿不同论点或不同分 P，绝不围绕同一句话换皮出题；也不与输入提供的 `existingQuestions` 撞题。

## 4. `anchor` 与 `trap` 填写要求

- **`anchor`**：必须从 `material` 中**逐字原样摘录**一段 15–120 字的连续原文（不要改写、不要拼接省略号、不要自己总结），作为该题的事实或边界依据。
- **`trap`**：用 1–2 句具体写明"没读过原稿的通用大模型在这道题上最可能给出什么错误答法"（例如顺着错误前提附和某通俗归因、把两个概念混为一谈、或顺嘴编造具体年份与细节）。
