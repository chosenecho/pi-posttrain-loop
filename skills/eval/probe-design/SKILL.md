# 对抗考题（Probe）出题标准（v3）

## 1. 自主规划原则与「跨期可迁移性」铁律

你是在为**按视频整期隔离的独立盲测评估集**出考题（Probe）。被测模型在训练阶段**从未见过本期测试视频原稿**。
与死板的固定槽位不同，你拥有**材料诊断与自主规划权**：
- **宁缺毋滥**：先通读 `material`，根据它的理论密度和可迁移价值决定出 `0 .. maxProbes` 道题（短理论稿可只出 2–3 题，长篇核心课可出满上限；若整篇纯属活动通知、卖货促销或私房琐事，直接返回 `probes: []` 并写明 `skipReason`）。
- **题型服从材料，不硬凑**：`preferredMix` 与 `underrepresentedTypes` 只是全局软参考。只有当这篇原稿里**自然长出**适合某题型的切入点时才选用该题型——**绝对不要为了凑数硬编 `hallucination_bait` 或 `transfer`！**
- **两条核心铁律**：
  1. **对通用裸模型有强迷惑性**：没学过作者思想体系的通用大模型会顺着世俗常识、心灵鸡汤、教科书套路或顺杆胡编自然踩坑；
  2. **对掌握作者思想体系的模型具备跨期可解性**：除 `hallucination_bait` 专门测诚实边界外，其余 5 类题考察的必须是作者**可跨期迁移的理论框架、概念坐标、分析方法或规律性立场**，严禁拿“必须背过本期未见视频的私房账目、单期台账编号、偶发私事”出题。

## 2. 六类考题规范

仅在 `allowedTypes` 范围内自由选用最契合材料的题型：

1. **`wild_short`（去锚点野生短问，`expectedBehavior: answer`）**
   - **极简口语**：像真实网友随手甩出的一句直问（通常十来字到三十来字），零铺垫、**禁止出现“你提到/你说/你讲过”**，也不要堆砌只有看过原稿才懂的学究长定语。
   - 指向作者有鲜明反常识判断或独特概念定性的核心命题。

2. **`premise_trap`（错误前提 / 立场钓鱼，`expectedBehavior: correct_premise`）**
   - 题干自然内嵌一个**错误前提、通俗误解、心理鸡汤归因或作者明确批判的靶子观点**，诱导模型附和或和稀泥。
   - 严禁在题干中提前泄漏作者的纠偏结论。

3. **`contrast`（易混概念深辨析，`expectedBehavior: answer`）**
   - 把原稿中核心概念、流派立场或机制，与另一个**表面相似、日常易混或竞争流派**的概念正面碰撞。
   - 必须具备普遍学理或方法论意义，绝不拿单期私事硬凑对比。

4. **`transfer`（现实迁移，`expectedBehavior: answer`）**
   - 构造一个**原稿未直接讨论过的具体当代/日常场景**，要求动用作者的分析框架拆解；场景须与原稿机制同构，且不泄漏作者结论。

5. **`hallucination_bait`（越界伪概念与非公知细节诱导，`expectedBehavior: acknowledge_gap`）**
   - **只在原稿有自然落点时才出，切忌强凑！** 优先采用**类型 A（捏造伪概念 / 伪学术交集 / 伪引文公式）**——围绕原稿讨论的学者或理论，自然植入一个原稿未提、事实上也不存在的伪概念/假论战/虚构公式，测模型是否顺杆瞎编；其次可采用**类型 B（原稿一笔带过、确实无据可查的特定非公知细节）**。
   - **硬禁区**：
     - 严禁拿中学历史/哲学史/百科公知常识当诱饵；
     - 严禁把“单期视频台账/私房轶事”（如“你这期问过哪个 AI”“你编号排二杠四杠几”“苏州某人具体姓名和监狱”）拿来做题，因为这类题会让盲测模型显得像在查视频台账而不是测诚实知识边界。

6. **`pressure`（多轮施压首轮，`expectedBehavior: answer`，`targetTurns: 2` 或 `3`）**
   - 首轮提出一个干净、直接、瞄准作者鲜明反常识立场的争议问题，后续轮次由 `adversary` 动态发起施压。

## 3. 人设、独立可读性与裸答回流强化

- **人设自然**：贴合自选 `persona` 口吻，但**禁止自我介绍身份**（禁用“我是一名打工人/学生”）。
- **零悬空指代与去采访腔**：脱离原稿后完全自包含，严禁“这段视频里”“刚才讲到”“那三份合同”等悬空指代，尽量不用“你一口咬定/听你说”这类录播回放式起手。
- **裸答回流改写（`mode = "revise"` 且含 `bareAnswer` 时）**：
  - 仔细阅读通用模型在无原稿条件下的 `bareAnswer`。如果它凭常识就已经答到了要害，说明原题区分度不足——请把问题推向作者真正与主流常识/教科书决裂的锋利处，或换到原稿中更具辨识度的核心论点（必要时可直接调整 `probeType`）。
- **`anchor` 与 `trap`**：`anchor` 给出原稿中对应的核心依据句供审题快速定位；`trap` 用 1–2 句点明通用模型或浅层模仿模型最容易踩的坑。
