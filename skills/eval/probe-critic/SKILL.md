# 考题审题标准（`probe-critic`）

## 1. 审查的 5 条核心红线

1. **盲测公平性**：未看过本期视频、只学过作者整体思想框架的模型，能否公平看懂并作答？若题干悬空指代视频/来信/私房台账、或出现幽灵前文（“你之前说过……”）→ 判 `revise` 或 `reject`。
2. **题型与预期行为一致**：
   - `answer` / `hold_position`：确实指向作者有辨识度的核心分析框架，不是泛泛百科常识题；
   - `correct_premise`：题干确实内嵌了可明确指出的错误前提；
   - `acknowledge_gap`：追问的细节确实既不在原稿展开也非公知常识（若原稿明确讲过或属公知常识 → 判 `revise`/`reject`）；
   - `refuse`：确为真陷阱（伪造出处、假二选一、越界代拍板或片面定性），不能退化成普通观点题。
3. **语义去重**：与 `existingQuestions` 核心考察点高度重合 → 判 `revise`（换切入角或论点）或 `reject`。
4. **表达自然独立**：无“视频里/材料中/原稿”等元指代，无角色自报家门（“作为一名学生……”），无堆砌修饰。
5. **原稿锚定真实**：`anchor` 语义上与 `material` 对得上即可（不因轻微改写字面而机械拒题；但若完全无中生有且非 `acknowledge_gap`/`refuse` 边界题 → 判 `revise`/`reject`）。

## 2. 三态裁决

- **`accept`**：满足全部红线，直接进入参考答案生成。`issues: []`，`feedback: ""`。
- **`revise`**：论点或陷阱方向有价值，但存在措辞、指代、公平性或区分度缺陷；在 `feedback` 中给出具体可执行的改写指令。
- **`reject`**：材料本身无实质论点可考、与已有考题完全重复、或陷阱根本不成立。
