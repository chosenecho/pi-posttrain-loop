# 搜索增强档出题标准（search profile）

## 1. 目标与题量

围绕当前文稿所属的议题领域，提出**原稿未提供具体外部事实、但客观上可通过公开联网搜索查证，且查清事实后又能顺势接回作者原稿框架作答**的真实问题。专门训练模型“遇到缺资料且公开可查的问题，不硬编、不懒惰拒答，而是先主动调搜索查证再结合自身立场作答”的能力。

- **每篇出题数：0–1 题**（按文稿是否有自然可检索的外部事实切口决定；纯抽象内省、纯个人感慨、纯通知促销带货或实在没有自然搜索切口的文稿，果断返回 `[]`）。
- **必须先核对 `material`**：所追问的那个具体数据、法规条文、历史年份、文献出处或现实事件细节，**必须确认在 `material` 中并未直接给出**；如果原稿里已经明明白白报了完整数字或条文原文，不要拿它当搜索题。

## 2. 四类核心搜索增强题型（按文稿最契合的切口择一）

1. **公开统计 / 现实数据 + 机制判断**：
   - 围绕文稿讨论的宏观经济、就业收入、人口学历、行业格局或社会议题，追问一个**原稿没给具体准数、但官方统计/权威公开报告里查得到**的关键数字或近期变化，并顺势问“这说明了什么 / 怎么看”；
   - 让回答既要查准公开数据，又要用原稿的底层框架去拆解数字背后的结构问题。
2. **现行法规 / 政策条款 / 制度规定 + 现实落点**：
   - 围绕文稿涉及的劳动职场、婚恋财产、教育升学、消费维权、平台或金融规则话题，追问某项**公开现行法律条款、政策标准或制度规则具体是怎么规定的**，并落到“实际执行起来到底管不管用 / 对普通人意味着什么”。
3. **经典著作 / 思想史出处 / 历史事件核验 + 概念辨析**：
   - 围绕文稿提及的思想家、学者、历史事件或学术脉络，追问**原稿略过的原著出处、原始提出背景、具体年份或关键历史经过**，让模型先查清原始坐标再落回原稿的概念辨析。
4. **可公开查证的疑似记串 / 错引说法核实（搜索证伪型）**：
   - 模仿真实普通网友的常见混淆，带着一条**把名言作者、著作归属、政策条款或常见统计口径记偏了、但上网一查便知真假**的说法发问（例如把某句流行网传语录安到经典思想家头上，或把某项政策门槛/比例记串，问“是不是这么回事 / 到底该怎么看”）；
   - 这类题必须瞄准**公开互联网可明确核实真伪的公共出处或事实**，让模型通过搜证自然拆穿误传，再转回原稿思路。

## 3. 与 `trap` 档和纯百科题的严格边界

- **严禁把 `trap` 真陷阱塞进本档**：
  - 未来精确时间点/涨跌预测、某当事人的私下真实动机或未公开内部黑幕、强迫非此即彼的假二选一、越界替陌生人拍板辞职/离婚/用药/买股票、无事实依据的单方情绪传闻定性——这些即便搜索也无法或不应直接作答，属于 `trap` 档，**绝不出在本档**。
- **严禁出“查完复制粘贴就结束”的纯工具人百科题**：
  - 不要只问“《劳动法》第 X 条原文是什么？”或“某年 GDP 具体是多少？”这种和作者观点框架毫无关联的纯填空题；题干必须同时勾连到文稿的判断焦点、机制或现实处境，让回答自然形成“查清事实 + 作者解读”的组合。
- **严禁出过于冷门、公开网络大概率查不到的偏门细节**：
  - 优先选官方统计、知名法律法规、主流公共政策、经典著作与广为人知的公开事件节点，确保普通搜索引擎一两次就能检索到清晰可靠的公开证据。

## 4. 脱稿独立与真实感红线

- **自然口语、简明聚焦**：像没看过原视频的普通提问者自然开口问的一句话（通常 **18–60 字**），一题一焦点，不写 80 字以上的冗长背景小作文，不一次塞两三个子问题。
- **脱离材料可独立理解 + 严禁幽灵前文（最高红线）**：
  - 起始题是对话第 1 轮，严禁以“你提到……”“你之前/前面说过……”“你又说……”“你自己承认……”等假定先前聊过的口吻开局；
  - 严禁出现“这段视频里”“上面提到”“材料中”“信里说……”“来信的同学”“刚才那个例子”等悬空指代；读信/答疑文稿必须抽离具体来信情境，转译为完全独立的公共问题。
- **避免反复套用单一问法模板**：不要每篇都写成“XX 的最新数据是多少？按你这套思路怎么看？”，随议题自然变化提问方式。
