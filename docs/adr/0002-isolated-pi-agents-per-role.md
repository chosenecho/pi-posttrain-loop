# 0002. 每个角色调用均启动独立无状态 Pi Agent 并实行角色级 Skill 白名单隔离

每次调用模型（出题、作答、质检、追问、评分要点抽取、思考补写及对抗评测各角色）均创建全新的无状态 Pi Agent 实例，仅通过显式构造的最小 JSON 消息传递当前步骤所需的上下文，且每个角色只能加载其专属的 `SKILL.md`。

如果在同一个多轮 Agent 会话里交替扮演“作答者”与“质检员”，或者让作答角色看到质检评分细则、让评测出题角色看到训练出题模板，模型会迅速产生自我迎合偏差（Self-bias）与评价标准串味，且第 2 次返工重答时携带的历史废案会严重污染上下文并推高 Token 成本。

## Consequences

- 第 $N$ 次返工重答时，`answer` 角色只接收原始材料、当前问题、上一版回答与上一轮质检反馈（携带前序已通过轮次的干净对话历史），绝不携带更早的失败草稿或内部质检判定标签。
- 每次运行前必须将实际注入的系统提示词与各角色 Skill 正文及 SHA-256 快照写入数据库，确保任意历史结果可精确复现当时的角色边界。
